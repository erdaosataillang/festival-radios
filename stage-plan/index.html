ステージ図面

ステージタイプを選んで、新しい図面を作成します。

変更はサーバーに自動保存されます。

ステージ寸法

吊り物

オブジェクト

配布元のSVGをダウンロード ↗

テキスト

図面へドラッグして配置します。配置後は図面上で直接入力できます。

線

始点と終点を順に指定します。図面へドラッグして始点を置くこともできます。

機材を選び、図面をクリックして配置します。

レイヤー

上にあるレイヤーほど手前に表示します。新規オブジェクトは選択中のレイヤーに入ります。

オブジェクト

複数選択してグループ化できます。

配置設定

図面のオブジェクトを選んでください。

原点は舞台の左奥です。左側・奥側はマイナスで入力できます。

平面図

スペースキーで図面を移動 · Optionキーで吸着を一時解除

機材表

オブジェクトをドラッグして移動。四隅でサイズ変更、下のハンドルで回転できます。

ショートカットキー

⌘ / Ctrl + S　今すぐ保存
⌘ / Ctrl + D　選択中のオブジェクトを複製
⌘ / Ctrl + Z　元に戻す
⌘ / Ctrl + Shift + Z または Ctrl + Y　やり直す
⌘ / Shift ＋ クリック　複数選択
矢印キー　機材を移動（Shiftで大きく移動）
Delete / Backspace　選択したオブジェクトを削除
＋ / −　図面の拡大・縮小
右クリック / Shift + F10　編集メニュー
Esc　配置モードを解除

オブジェクトの置き換え

ステージタイプを選択

舞台形状・幕

座標はステージ左奥から右・手前に向かって計測します。単位はcmです。

外周に沿って「横位置, 奥行位置」を1行に1点。最後の点から最初の点へは自動で閉じます。

1行ごとに「幕の名前, 始点の横, 始点の奥行, 終点の横, 終点の奥行」。幕のない会場は空欄にします。
